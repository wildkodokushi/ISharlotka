# iSharlotka — Интернет-магазин авторских чехлов

## Стек технологий
- **Frontend:** HTML5, CSS3, JavaScript (vanilla)
- **Backend:** PHP 8.0+
- **База данных:** MySQL 5.7+ / MariaDB 10.3+
- **Сервер:** Apache (с mod_rewrite) или Nginx

---

## Установка

### 1. Требования
- PHP 8.0+ с расширениями: PDO, PDO_MySQL, fileinfo
- MySQL 5.7+ или MariaDB 10.3+
- Apache с mod_rewrite или Nginx
- Composer (не требуется, зависимостей нет)

### 2. База данных
```sql
-- Создайте БД и выполните скрипт:
mysql -u root -p < database.sql
```

Или через phpMyAdmin:
1. Создайте базу данных `cases_shop` (кодировка `utf8mb4`)
2. Импортируйте файл `database.sql`

### 3. Конфигурация
Откройте файл `/config/db.php` и измените параметры подключения:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'cases_shop');
define('DB_USER', 'your_user');
define('DB_PASS', 'your_password');
```

### 4. Настройка веб-сервера

**Apache** — убедитесь, что включён `mod_rewrite` и `AllowOverride All` для директории сайта.

**Nginx** — добавьте в конфиг:
```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

### 5. Права на загрузку файлов
```bash
chmod -R 755 uploads/
chmod -R 777 uploads/cases/
```

## Возможности

### Для покупателей
- Регистрация и авторизация
- Каталог (только для авторизованных)
- Фильтрация по устройству, материалу, коллекции
- Поиск по каталогу
- Карточка товара с подробным описанием
- Добавление авторского дизайна/пожеланий к заказу
- Корзина (управление количеством, удаление)
- Оформление заказа
- История заказов со статусами

### Для администраторов
- Дашборд со статистикой (пользователи, заказы, выручка)
- Полное управление каталогом (CRUD)
- Загрузка изображений для чехлов
- Управление материалами
- Управление моделями устройств
- Управление пользователями (просмотр, удаление)
- Управление заказами (изменение статуса, просмотр состава)
